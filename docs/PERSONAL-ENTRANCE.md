## 设计判断（提案，非官方）

- 主题：水 / 冰与静眠。冷银蓝为主色，少量暖金呼应原图的金色水线。
- 文案：主标题「水光之下 / 仍在等你」（两行，无标点）；副题「沉入涟漪，再被浮起。」；品牌 `DeepSeek`。
- 图层顺序（低 → 高）：底色渐变 → hero 场景层 → 可读性暗角（veil）→ 底部冷色波带 →
  跃水鱼群 → 标题 / 品牌 → 水波退场画布。
- **分层登场（保留）**：`0–0.70` 波带与场景铺开；`0.48–1.38` hero 落位；
  `1.05–1.65` 文案与品牌建立层级；`2.40` 后停留等待用户。原分镜中 `1.36–1.82`
  的闭眼叠化不适用（无表情素材）。
- **水波交接（保留）**：退出仍由 `welcomeWaterWaves()` 同一几何同时驱动水体与欢迎层
  遮罩，剩余可见度依次 `100% → 56% → 20% → 0%`，从指针位置扩散；键盘退出取中心点。
- 移除：祭典折扇、红屏、飘带、锦鲤贴图，以及挥手 / 眨眼局部动作（均无对应素材，
  属本次设计判断）。配色适配：底部波带、烟花、跃水鱼群改为冷银蓝 / 淡金。

## 修订记录

### 第二轮（2026-10-10，按用户反馈）

用户反馈：宽屏左下角品牌 `DeepSeek` 与副题「沉入涟漪，再被浮起。」轻微重叠；主标题的标点可去掉。

- 主标题去掉标点，改为「水光之下 / 仍在等你」两行。
- 重叠根因：字号只用 `cqw`（容器宽度单位）计算，`1920×869` 这类**矮宽窗口**会把标题放大到
  挤压副题，直到与底部锚定的品牌相撞。改为高度感知的 `min(cqw, vh)`：主标题
  `min(9.2cqw, 15vh)`、副题 `min(1.3cqw, 2.1vh)`、品牌 `min(2cqw, 2.9vh)`；标题上移至
  `top:24%`，品牌下移至 `bottom:13%`。窄屏媒体查询同样改用 `min()`。
- 验证方式：在浏览器中**实测元素盒**（而非仅看截图），检查副题下沿与品牌上沿的间距。

| 视口 | 副题下沿 | 品牌上沿 | 间距 |
| --- | --- | --- | --- |
| 1920 × 869（用户窗口） | 546 | 700 | 154 |
| 1440 × 900 | 559 | 725 | 166 |
| 2560 × 1080 | 677 | 873 | 196 |
| 390 × 844（窄屏） | 230 | 716 | 486 |

四档视口均无重叠（间距 > 0）。改动后 `pnpm test` 仍 16/16、`pnpm run test:browser` 仍 36/36。
注：首次测量脚本误查了宿主元素的 light DOM 而返回空值，属假阴性；已改为读取 shadow root 后重测。
